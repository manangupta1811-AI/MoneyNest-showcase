# 💰 MoneyNest

**An offline-first money manager for Android and iOS, built with Flutter.**
English and Hindi from day one. No internet needed, no sign-up needed.

> This is a showcase page. The source code is private and there are no screenshots here on purpose, because the real app can hold real money data.

## Why I'm building it

Most money apps need an account, need internet and only speak English. I wanted one that my family can use at home or in a shop, in Hindi or English, with simple words and no clutter.

## What it does

- **Piggy Bank and Earnings.** Two separate balances, so savings and income never get mixed up.
- **History is the truth.** Every balance is rebuilt from the list of transactions, so a number can never silently drift away from what really happened.
- **Profiles.** Separate profiles for different people, with optional password protection and optional login.
- **Backup and restore.** Save your data and bring it back.
- **Hindi and English.** The whole interface works in both languages.
- **Works offline.** Your data stays on your device.

## Coming next

Sales, expenses, inventory, goals and reports, aimed at small shops and families.

## How it's built

- Flutter and Dart, one codebase for Android and iOS
- GitHub Actions for automatic builds and tests
- Signed release builds, so new versions update the installed app
